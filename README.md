# Function-space bounds for neural networks

The current paper is **Certified adaptive integration of ReLU network norms**,
by Johannes Gründler, Moritz Maibaum and Philipp Petersen.

The standalone, versioned code and numerical evidence for the planned ACOM
submission are in the [19 November 2026 reproducibility snapshot](https://github.com/RubenDeAngelo/Function-Space-Bounds-for-NN/tree/4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a).
Its immutable commit is `4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a`.

- [Reproduction instructions and experiment map](https://github.com/RubenDeAngelo/Function-Space-Bounds-for-NN/tree/4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a/README.md)
- [Validation scope and results](https://github.com/RubenDeAngelo/Function-Space-Bounds-for-NN/tree/4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a/release/VALIDATION.md)
- [Integrity manifest](https://github.com/RubenDeAngelo/Function-Space-Bounds-for-NN/tree/4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a/release/SHA256.json)
- [Download the complete source and frozen records](https://github.com/RubenDeAngelo/Function-Space-Bounds-for-NN/archive/4c2b9ce6df9ac5ed0b19e6168998b259a7ce049a.zip)

The snapshot contains standalone paper backends, frozen network coefficients,
configurations, exact endpoint histories, validation evidence, figure/table
assets and reproduction instructions. It has no Mothercode dependency. Code
and numerical records are included together; no separate local artifact folder
is required. Replay uses saved coefficients and does not retrain the networks.

Software is MIT licensed. Scientific figure artwork retains the authors'
copyright; the manuscript text and manuscript PDFs are not distributed in this
code release. See the snapshot's RIGHTS.md for scope and provenance.

The implementation files on this `master` branch describe an earlier paper
version. Use the immutable snapshot above for the current paper. The earlier
README is preserved in [docs/legacy-readme.md](docs/legacy-readme.md) and in Git
history. This repository does not assert that the planned ACOM submission has
been accepted or peer reviewed.
