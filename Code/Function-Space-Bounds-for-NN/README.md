# Current paper implementation

This directory contains the standalone, pre-migration paper code and all required
frozen experiment packages. Use the repository-root [README](../../README.md)
and [release reproduction wrapper](../../release/reproduce.py).

The code and preserved backends have no Mothercode dependency. Historical entry
points, unrelated older campaigns and their original environment locks remain for
provenance. Their old instructions are in [the archived README](../../release/LEGACY_CODE_README.md).
The current figure/table map, installation, validation scope and MIT licence are
specified at the repository root.
